## Танилцуулга

Orchuulga.mn бол англи, хятад, орос, япон, солонгос, турк, герман, польш хэлээр ажилладаг
баталгаат орчуулгын товчооны вэбсайт. Сайт WordPress дээр ажилладаг байсан бөгөөд хакердуулсан
байв: хуудсууд руу шургуулсан script утаснаас орсон зочин бүрийг зар сурталчилгааны сүлжээ рүү
шилжүүлдэг байсан.

```html
<script>
  (function () {
    if (/Android|iPhone|iPad|iPod|BlackBerry|Windows Phone/i.test(navigator.userAgent)) {
      location.href = "https://[зар сурталчилгааны сүлжээ]/link?z=…&var=orchuulga";
    }
  })();
</script>
```

## Миний хийсэн ажил

Шургуулсан script-ийг 56 хуудаснаас бүгдээс нь устгаад, сайтыг WordPress-ээс гаргаж, хуудас бүрийг
статик HTML болгон урьдчилан рендерлэдэг SvelteKit апп руу шилжүүлсэн. Товчооны дизайн, кирилл
үсэгтэй URL-ууд, хайлтын мета өгөгдлийг хэвээр нь хадгалсан.
