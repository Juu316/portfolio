## Context

Orchuulga.mn is the website of a certified translation office that works in English, Chinese,
Russian, Japanese, Korean, Turkish, German and Polish. The site ran on WordPress, and it had been
compromised: a script injected into its pages sent every visitor on a phone to an ad network.
{/* src: orchuulga.mn scripts/strip_mobile_redirect.py, commit 669ef3d */}

```html
<script>
  (function () {
    if (/Android|iPhone|iPad|iPod|BlackBerry|Windows Phone/i.test(navigator.userAgent)) {
      location.href = "https://[ad network]/link?z=…&var=orchuulga";
    }
  })();
</script>
```

## What I did

I removed the script from all 56 pages it had been planted in, then moved the site off WordPress
into a SvelteKit app that prerenders every page to static HTML, keeping the agency's design, its
Cyrillic URLs and its search metadata.

<Decision
  locale="en"
  title="Keep the pages, drop WordPress"
  problem="The agency wanted its site back as it was, with its URLs and search rankings intact — but WordPress was how the attacker got in."
  tradeoff="Content changes now mean editing HTML and redeploying; there is no CMS."
>
  A one-off script turned a static export of the site into one SvelteKit route per page, and every
  route is prerendered at build time. The old SEO tags are stripped and written again with correct
  canonical URLs, and the sitemap is generated from the route folders, with the Cyrillic slugs
  encoded.
</Decision>

<Decision
  locale="en"
  title="Old theme scripts in a new framework"
  problem="The theme's sliders and menus expect a full page load. Scripts inserted as HTML never run, and on client-side navigation they would attach their listeners twice."
  tradeoff="Moving between pages is a full reload, as it was on WordPress."
>
  After each render the scripts are recreated as real `<script>` elements, and every link inside
  the page content forces a full page load.
</Decision>

## Outcome

All 56 pages are served as static HTML from a Node server on Railway, behind Cloudflare, and the
injected script is gone from every one of them.
